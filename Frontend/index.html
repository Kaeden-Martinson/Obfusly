Getting Started

Welcome to JsScramble! Follow these steps to get started with obfuscating your JavaScript code.

  1. Navigate to the Obfuscate tab - Click "Obfuscate >" in the navbar to access the obfuscation tool
  2. Paste your code - Copy and paste your JavaScript code into the input editor
  3. Configure settings - Customize your obfuscation preferences (optional)
  4. Click Obfuscate - Process your code with the selected options
  5. Copy output - Copy the obfuscated code from the output editor

Configuration Guide

JsScramble provides extensive configuration options to customize your obfuscation:

  • Name Generation: Choose between Minify, Zalgo, and Invisible character styles
  • Number Encoding: Convert numbers to various base systems (Binary, Hex, Octal, JSFuck)
  • String Encoding: Apply multiple encoding layers to string literals
  • Object Properties: Obfuscate object keys and member access
  • Anti-Debugging: Add debugger detection and anti-tampering measures

Obfuscation Modes

  • Minification: Fast obfuscation focusing on code reduction
  • Conservative: Balanced approach maintaining readability hints
  • Aggressive: Maximum obfuscation for maximum protection
  • Custom: Fine-tune each obfuscation option individually

Best Practices

Before Obfuscating

  • Test your code thoroughly - Ensure your code works perfectly before obfuscation
  • Keep backups - Always maintain a copy of your original source code
  • Version control - Use Git or similar to track changes
  • Document your code - Add comments while code is still readable

Obfuscation Strategy

  • Use aggressive obfuscation - Maximum protection for sensitive code
  • Enable anti-debugging - Deter reverse engineering attempts
  • Apply compression - Reduce file size while maintaining obfuscation
  • Use multiple encoding layers - Combine different obfuscation techniques

After Obfuscation

  • Test thoroughly - Verify all functionality works as expected
  • Check performance - Monitor for any significant slowdowns
  • Verify compatibility - Test in all target browsers and environments
  • Monitor error logs - Watch for issues from obfuscated code in production

Security Considerations

  • Obfuscation is not encryption - Don't store sensitive data in client-side code
  • Combine with other techniques - Use HTTPS, Content Security Policy, and other security measures
  • Update regularly - Keep your obfuscated code current with security patches
  • Use source maps carefully - Never expose source maps in production

Performance Tips

  • Monitor bundle size - Obfuscation can increase code size; use compression
  • Minify aggressively - Combine obfuscation with minification for best results
  • Use lazy loading - Split code into smaller chunks and load on demand
  • Profile before and after - Measure performance impact in your specific use case
