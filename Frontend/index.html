Documentation

Getting Started

Welcome to JsScramble! Follow these steps to get started with obfuscating your JavaScript code.

  1. Navigate to the Obfuscate tab
  2. Paste your JavaScript code in the input editor
  3. Visit the CONFIG tab to customize settings
  4. Click the Obfuscate Code button
  5. Copy the protected code and use it in your project

Configuration Guide

JsScramble provides extensive configuration options to customize your obfuscation:

  • Build Settings: Choose your target environment and naming style
  • Number Encoding: Configure how numbers are encoded and cached
  • String Encoding: Customize string protection strategies
  • Code Protection: Add protection layers to your code structure
  • Security & Integrity: Enable anti-debugging and integrity checks

Obfuscation Levels

  • Minimal: Light obfuscation for quick protection
  • Standard: Balanced approach maintaining readability hints
  • Maximum: Complete code transformation with maximum protection
