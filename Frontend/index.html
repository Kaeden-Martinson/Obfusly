i Encode Strings BOOLEAN DEFAULT: TRUE Encodes all string literals in your code. Utilizes a robust encoding mechanism (Unicode and XOR) to protect sensitive information.
i Conceal String Values BOOLEAN DEFAULT: FALSE Hides the true meaning of string values by applying additional obfuscation layers such as Base64, array shifting, and XOR encoding decoded at runtime.
i String Splitting NUMBER (0-10) DEFAULT: 3 ⚠ Can increase obfuscation output significantly Creates as many splits in Strings as specified by the value which increases the complexity of the obfuscation by encoding subStrings separately.
3
i Optimize String Cache BOOLEAN DEFAULT: TRUE Caches decoded strings during execution. Improves runtime speed at the cost of slightly larger output size and potentially easier string extraction for attackers. Disable to prioritize smaller file size and maximum obfuscation over performance.

Number Protection

i Number Obfuscation BOOLEAN DEFAULT: TRUE Encodes numeric literals. Prevents extraction of numeric constants from your code.
i Global Int Concealment BOOLEAN DEFAULT: TRUE Applies base-integer concealment which takes all numeric literals from 1-100 and assigns them to a variable which is then used throughout the code.
i Multiple Variable Assignments BOOLEAN DEFAULT: FALSE ⚠ Significantly increases output size (400 vs 100 vars) Generates many variable assignments for base integers which helps randomize and obscure the numeric values used throughout the code.
i Optimize Number Decoding Cache BOOLEAN DEFAULT: TRUE ⚠ Use for large code bases. Would recommend if you have a higher "Function Encoding Strength". Caches decoded numbers during execution for performance optimization.
i Default Number Format ENUM DEFAULT: JSFUCK Choose the default number encoding format for the Base Integer encoding: JSFuck (!![]+!![]+!![]), Hexadecimal (0x...), or Octal (0o...), Binary (000100...), Refractal ((~'2') ** ~-3 + 6).

Security Features

i Anti-Debugger BOOLEAN DEFAULT: FALSE ⚠ Prevents legitimate debugging. Use with caution. Detects and disables browser developer tools and debuggers at runtime.

i Disable Console Output BOOLEAN DEFAULT: FALSE Removes all console.log and debugging output.

Frequently Asked Questions

Everything you need to know about Obfusly.

Obfuscation is the process of transforming readable source code into a functionally identical but highly unreadable form. It makes reverse engineering, and tampering significantly harder without impacting runtime behaviour.

Obfusly is engineered for low performance impact. Our obfuscation passes are benchmarked continuously to ensure the output runs at nearly the same speed as the original. Enabling features like Integrity Verification or Anti-Debugger adds a negligible overhead only during startup.

While no obfuscation is theoretically unbreakable, Obfusly employs multiple independent layers — identifier mangling, string array encoding, integer concealment, and integrity checks — making automated deobfuscation extremely time-consuming and expensive to reverse engineer.
