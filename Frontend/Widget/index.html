🎯 Obfusly Widget

Embed the power of code obfuscation on your website

⚡ Quick Start

Add one line of code to your HTML and you're done:

<script src="https://obfusly.com/widget/embed.js"></script>

✨ Features

  • Lightweight (< 5KB)
  • Easy Integration
  • Fully Responsive
  • Customizable Colors
  • CORS-Enabled
  • No Dependencies
  • Mobile Friendly
  • SEO Safe

⚙️ Configuration Options

Customize the widget by adding query parameters:

Option Values Default Example
position left, right right ?position=left
bgColor Hex (URL encoded) %23000000 ?bgColor=%232e6bff

📍 Position

Right: position=right

Left: position=left

🎨 Colors

Black: %23000000

Blue: %232e6bff

Cyan: %2388ddff

📋 Examples

1. Default (Right, Black)

<script src="https://obfusly.com/widget/embed.js"></script>

2. Left Position

<script src="https://obfusly.com/widget/embed.js?position=left"></script>

3. Blue Background

<script src="https://obfusly.com/widget/embed.js?bgColor=%232e6bff"></script>

4. Left + Cyan

<script src="https://obfusly.com/widget/embed.js?position=left&bgColor=%2388ddff"></script>

5. Async Loading (Recommended)

<script async src="https://obfusly.com/widget/embed.js"></script>

6. Dynamic Injection

const script = document.createElement('script');
script.src = 'https://obfusly.com/widget/embed.js';
script.async = true;
document.head.appendChild(script);
